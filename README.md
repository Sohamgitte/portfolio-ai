# Soham Gitte — Portfolio

A premium, responsive portfolio website for Soham Gitte — developer, entrepreneur and creative problem-solver.

## Files

- `index.html` — semantic portfolio markup and resume content
- `styles.css` — responsive dark-blue visual system
- `script.js` — mobile navigation and scroll reveal animations
- `profile.jpg` — optional profile image (add your image with this filename)

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Add profile image

Place the supplied portrait in the repository root and name it `profile.jpg`. The page has a fallback monogram if the image is not present.

## GitHub Pages

1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose the `portfolio-ai-site` branch and `/ (root)`.
4. Save and wait for the Pages URL to become available.
